# 연구실 일간보고 작성 스킬

## 1. 작업 소개

연구 활동 및 업무 내용을 매일 일간보고 형식으로 작성하고 있다. 이 과정에서 반복적으로 수행하는 문장 수정과 보고서 정리 작업을 효율적으로 진행하기 위해 AI 스킬을 제작하고자 한다.

## 2. 반복 작업

하루 동안 수행한 활동을 간단하게 입력하면 AI가 맞춤법과 띄어쓰기를 수정하고, 문장을 자연스럽게 다듬어 일간보고 형식으로 정리한다.

## 3. 일간보고 작성 원칙

- 실제 수행한 활동과 수치를 변경하지 않는다.
- 맞춤법과 띄어쓰기를 수정한다.
- 문장의 의미를 유지하면서 자연스럽게 연결한다.
- 서로 다른 활동은 번호를 구분하여 작성한다.
- 보고서에 적합한 정중하고 간결한 문체를 사용한다.
- 입력하지 않은 활동, 실험 결과, 시간 등을 임의로 추가하지 않는다.
- 불필요한 설명이나 과장된 표현은 사용하지 않는다.

## 4. 기대효과

반복적인 일간보고 작성 시간을 줄이고, 일관된 형식과 문체로 연구 활동을 정리할 수 있을 것으로 기대된다.
